Aquí ocurre una de las partes más importantes.


Box64 hace la traducción de instrucciones:

```
   ↓

   ↓
```

### Wine


Wine hace otra función diferente.


Box64 resuelve:


> "¿Cómo ejecuto código x86/x64 en ARM?"


Wine resuelve:


> "¿Cómo proporciono las APIs que espera un programa Windows?"


Por ejemplo, una aplicación Windows puede pedir:


```
CreateWindowEx()
DirectX
Registry
kernel32
user32
GDI
```


Wine proporciona implementaciones compatibles.


Por eso:


```
.EXE
 ↓
Wine
 ↓
APIs Windows
 ↓
Box64
 ↓
ARM64
```

- se adapta mejor a la pantalla del teléfono;
- evita desperdiciar recursos renderizando una superficie innecesariamente alta;
